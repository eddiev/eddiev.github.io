# Product Designer Portfolio

Static starter site for a personal or professional product designer portfolio.

## Run locally

From `/Users/eddiev/Documents/Personal`:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Customize first

- Update the name, headline, and intro copy in `index.html`
- Replace the three placeholder case studies with real project summaries
- Replace the contact links with your actual email and LinkedIn
- Add a PDF resume link if you want this to function as both portfolio and resume

## Files

- `index.html`: structure and content
- `styles.css`: visual system, layout, and responsive behavior
- `script.js`: reveal-on-scroll and footer year
